# AI Smart Call Center Dashboard

A futuristic AI-powered Call Center dashboard built using HTML, CSS, and JavaScript.
This project simulates a real-time call center with voice recognition, department routing,
customer mood detection, and live transcript display.

## Key Features
- Simulated incoming calls
- Real-time voice recognition (Web Speech API)
- AI agent personas for different departments
- Automatic intent detection & call routing
- Customer mood analysis
- Live transcript & activity logs
- Modern dark UI dashboard

## Departments Supported
- Reception
- Sales
- Marketing
- Refunds
- Inventory

## Technologies Used
- HTML5
- CSS3 (Glassmorphism UI)
- JavaScript
- Web Speech API (Speech Recognition & Synthesis)

## Browser Support
⚠️ Works best on Google Chrome / Microsoft Edge  
(Web Speech API required)

## How to Run
1. Open `index.html` in Google Chrome
2. Click **Simulate Incoming Call**
3. Allow microphone access
4. Speak to interact with AI agents
